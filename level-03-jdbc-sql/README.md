# Level 3: Database Connectivity (JDBC & SQL)

Welcome to **Level 3** of Java Forge! This level bridges Java applications with relational database systems using raw SQL, JDBC drivers, and connection management.

## 🎯 Concepts Covered
- JDBC Drivers, Connections, and Statements
- `PreparedStatement` & SQL Injection prevention
- ACID Transactions and rollback management
- Complex Relational Queries (Inner, Left, Right Joins, Aggregations)
- Database schema normalization (1NF, 2NF, 3NF)
- Connection Pooling and resource management
