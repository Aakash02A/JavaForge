# Level 9: Docker, DevOps & Cloud

Welcome to **Level 9** of Java Forge! This level equips you with containerization, deployment pipelines, infrastructure, and observability tooling to ship applications to production.

## 🎯 Concepts Covered
- Multi-stage Docker builds for minimal, secure container images
- Multi-container orchestration with Docker Compose
- Continuous Integration & Continuous Delivery (CI/CD) with GitHub Actions
- Cloud deployment on AWS (EC2, systemd, security groups)
- Metrics collection and dashboards with Prometheus & Grafana
- Centralized log aggregation and querying with the ELK stack (Elasticsearch, Logstash, Kibana)
