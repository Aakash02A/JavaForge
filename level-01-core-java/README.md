# Level 1: Core Java Fundamentals

Welcome to **Level 1** of Java Forge! This level establishes foundational object-oriented programming concepts in Java using practical, console-based projects.

## 🎯 Concepts Covered
- Classes, Objects, and Constructors
- Object-Oriented Programming (Encapsulation, Inheritance, Polymorphism, Abstraction)
- Interfaces and Abstract Classes
- Java Collections Framework (`ArrayList`, `HashMap`)
- File I/O and Scanner input
- Robust Exception Handling
