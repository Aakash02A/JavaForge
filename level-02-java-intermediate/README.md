# Level 2: Java Intermediate

Welcome to **Level 2** of Java Forge! This level elevates your Core Java skills to write idiomatic, performant, and concurrent Java code.

## 🎯 Concepts Covered
- Java Streams API (`filter`, `map`, `reduce`, `collect`)
- Java Generics (Type parameters, bounds)
- File and Log Streaming / Regex Parsing
- Sorting with `Comparable` & `Comparator`
- Data Structure design (LRU Cache, LinkedHashMap)
- Multithreading and Concurrency (Producer-Consumer, BlockingQueue)
- Network Programming (TCP Sockets, Client-Server)
- Hashing and Encoding Algorithms
