# Employee Payroll

A simple payroll system that demonstrates interfaces and polymorphism in Java.

## Features

- Supports full-time and part-time employees
- Uses an interface for payroll calculation
- Calculates total payroll for all employees
- Provides a CLI menu for payroll operations

## Run

```bash
mvn compile exec:java -Dexec.mainClass=com.javaforge.payroll.Main
```

## Testing

```bash
mvn test
```
