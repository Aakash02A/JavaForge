# Project Idea

Build a **Quiz Application** that allows users to take multiple-choice quizzes and view their scores.

# Problem Statement

Creating and taking quizzes in a simple, automated format is useful for education and self-assessment.

The **Quiz Application** is a Java console application that presents questions, takes answers, and grades them automatically.

# Objectives

- Store quiz questions.
- Take a quiz.
- View final score.

# Features

- Add Questions (Admin)
- Take Quiz
- View Score
- Exit

# Tech Stack

- Java (Core Java)
- OOP
- ArrayList
- Scanner
