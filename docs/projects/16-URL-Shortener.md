# Project Idea

Build an **URL Shortener** that takes a long URL and generates a compact, easily shareable short URL.

# Problem Statement

Long URLs can be difficult to share, read, or embed in constrained environments. 

The **URL Shortener** is a Java application that allows users to submit a long URL and receive a simplified, shorter alternative. It also needs to map the short URL back to the original long URL.

# Objectives

- Generate a unique short URL for any valid long URL.
- Retrieve the original long URL when given a short URL.
- Handle multiple URLs and avoid duplicates for the same input.

# Features

- Shorten URL
- Expand URL

# Tech Stack

- Java (Core Java)
- Maps (HashMap)
- UUID Generation
