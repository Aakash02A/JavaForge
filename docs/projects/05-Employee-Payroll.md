# Project Idea

Build an **Employee Payroll System** that allows users to manage employee salaries and records from the console.

# Problem Statement

Managing employee payroll manually can be error-prone and tedious for small organizations.

The **Employee Payroll System** is a Java console application that automates salary calculations based on base pay, deductions, and bonuses.

# Objectives

- Store employee details.
- Calculate net salary.
- View all employees.

# Features

- Add Employee
- View Employees
- Calculate Payroll
- Exit

# Employee Details

- Employee ID
- Name
- Designation
- Base Salary
- Deductions
- Bonus

# Tech Stack

- Java (Core Java)
- OOP
- ArrayList
