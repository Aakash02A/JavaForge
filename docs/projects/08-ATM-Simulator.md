# Project Idea

Build an **ATM Simulator** that mimics the basic functionalities of an Automated Teller Machine.

# Problem Statement

Understanding how banking systems manage accounts securely is a foundational software concept.

The **ATM Simulator** is a Java console application that lets users check balances, deposit money, and withdraw funds securely with a PIN.

# Objectives

- Authenticate user via PIN.
- Manage account balance.

# Features

- Check Balance
- Deposit Money
- Withdraw Money
- Change PIN
- Exit

# Tech Stack

- Java (Core Java)
- OOP
- Scanner
- Conditional Statements
