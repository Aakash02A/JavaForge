# Project Idea

Build a **Contact Book** that allows users to manage contacts (phone numbers, emails) from the console.

# Problem Statement

People need a simple digital phone book to store and look up contact information quickly.

The **Contact Book** is a Java console application that provides an easy way to store, retrieve, update, and delete contacts.

# Objectives

- Store contact information.
- Search for a contact by name.
- View all contacts.

# Features

- Add Contact
- View All Contacts
- Search Contact
- Update Contact
- Delete Contact
- Exit

# Tech Stack

- Java (Core Java)
- OOP
- ArrayList
- Scanner
